# Buyer Discovery Questions

Use these before building beyond the Compensation Definition + Match Impact Auditor.

## Advisor / consultant questions

1. How often do you see payroll compensation or eligibility errors create match or contribution issues?
2. Who usually catches those issues today: sponsor, payroll, recordkeeper, TPA, auditor, or advisor?
3. When issues are found, what is the biggest bottleneck: identifying the error, quantifying dollars, getting source files, assigning responsibility, or documenting the fix?
4. Would a payroll-to-recordkeeper integrity scan help you in existing plan reviews?
5. Would it help in prospecting?
6. What would make the report credible enough to show a sponsor?
7. What evidence would you need before you trusted the output?
8. Would you prefer a sponsor-facing report, advisor-only diagnostic, or audit workpaper packet?
9. Would you pay per plan, per batch of plans, or only if it found an issue?
10. What would make this a must-have instead of a nice-to-have?

## Sponsor questions

1. How confident are you that payroll applies the plan's compensation definition correctly?
2. Who owns payroll-to-recordkeeper reconciliation today?
3. Do you have multiple pay codes, employee classes, hourly workers, bonuses, overtime, commissions, or excluded compensation?
4. Have you ever had audit, testing, or correction issues tied to payroll data?
5. If a report found affected participants and estimated correction dollars, who would act on it?
6. What format would be useful: Excel, PDF, evidence ZIP, or all three?
7. Would you run this before audit season, after payroll changes, after vendor changes, or quarterly?

## TPA / auditor questions

1. What payroll data problems create the most rework during testing or audit?
2. What evidence do you usually need to validate compensation and match issues?
3. Would a deterministic exception file with source rows reduce review time?
4. What false positives would make you reject the tool?
5. What controls or disclaimers would be needed before using the output in client workpapers?

## Disqualifying answers

The opportunity is weaker if buyers say:

- compensation errors are rare in their plans
- payroll already owns this with strong controls
- they would not trust third-party calculations
- they only care after an auditor finds an issue
- they need full payroll/RK API integrations before any manual-file diagnostic is useful

## Strong buying signals

The opportunity is stronger if buyers say:

- they regularly see bad compensation or class data
- corrections are painful and time-consuming
- no one clearly owns the control
- they need better evidence packets
- they would use this in plan reviews or prospecting
- they would pay for a diagnostic scan before committing to full software
